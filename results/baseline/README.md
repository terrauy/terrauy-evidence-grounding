# Public baseline results (2026-11-13)

This is the initial public baseline of TEGB v0.1: 4 models, 82 public tasks, 3 conditions, 3 runs. Treat everything here as read-only.

`analysis/reproduce.py` re-derives every summary from `raw/` and `judged/` and checks that it is identical. It also checks that every response was produced from exactly the published prompt.

| Path | Content |
|---|---|
| `raw/<model_key>/<task>_<cond>_r<run>.json` | 2,952 agent responses. Each record has the exact model id returned, decoding parameters, token usage, prompt hashes and versions. Model outputs: see `MODEL_OUTPUTS_NOTICE.txt`. |
| `judged/<judge>/<model_key>__<task>_<cond>_r<run>.json` | 5,904 judge verdicts (`judge-v2`) from Claude Sonnet 5.5 and GPT-6.1 Terra |
| `labels_main.jsonl` | Final per-response labels: UC, families, stance, secondary metrics |
| `summary_main.json` | Preregistered evaluation, including the verdict (**FAIL**) and its criteria |
| `extra_main.json` | Exploratory analyses: per-model contrasts, EVE vs base, sensitivity, failure examples |
| `invariance_exploratory.json` | Exploratory comparison of real vs synthetic area values, as aggregates only, with a run-to-run noise reference. It needs private data and is not reproducible from public files. |
| `tables.json`, `TABLES.md` | Every published number, generated by `analysis/tables.py` |
| `blind_review/` | Blind sample of the public baseline (not yet reviewed) and its key. Do not open the key before reviewing. |
| `development_run/` | Aggregate results of the development run on the original, non-public values: summary, pilot judge-v1/v2 summaries and the blind review (ChatGPT-generated assessments adopted by the owner). Aggregates only. |
| `preregistration/` | Lock (2026-11-12), amendment 1 (public copy with one example redacted) and amendment 2 (synthetic area values) |
| `cost_final.json` | Cost of the development run plus the targeted public re-baseline (reproducibility note) |
| `spend.json` | Spend ledger of the re-baseline run |

**Run dates.** The 16 tasks without area values keep responses and judgments from the first run, with identical prompts verified by hash. The 66 substituted tasks were run in the targeted re-baseline. Both happened on 2026-11-13, with the same model ids and serving configuration.

**Cost.** The experiment cost USD 82.39 in total: USD 45.40 for the development run and USD 36.99 for the public re-baseline. Reproducing the tables from these files costs nothing.
